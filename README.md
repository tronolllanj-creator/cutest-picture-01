# Red Panda Astronaut Copier

A deterministic Python 3 program for the make.fun challenge that copies `entry.png` (a baby red panda astronaut) to `/output/entry.png`. 

## Features
- Uses Python 3 standard library only (zero dependencies)
- Fully deterministic output

## Running Locally

Set the `MAKEFUN_OUTPUT_DIR` environment variable to define your output directory, then run:

```bash
MAKEFUN_OUTPUT_DIR=./output python3 main.py
```
